Where we are

Every modern AI is a drawing someone made

  • Tokens go in here
  • Attention happens there
  • A feed-forward block follows
  • Stack it 100 times, read the answer off the end
  • Train it by nudging every weight a tiny bit toward a goal a human picked
The theory

A system shaped by a human
carries the limits of that human

Human fingerprints on today's AI

  • The data is human text. Our biases, our ceiling.
  • The goal is a proxy we chose. Optimize it hard and you get flattery and confident errors.
  • The shape is fixed. Nothing changes after training.

The alternative

A brain was never designed. It was selected.

01

No prescribed wiring

Nobody decided which neuron talks to which. Connections that helped survival stayed. The rest did not.

02

It never stops

No forward pass. A brain runs from birth to death. Inputs arrive while it is already thinking. Actions happen when activity crosses a threshold.

03

Mistakes are fatal

Evolution does not nudge a weight. The animal that errs does not reproduce. Survivors define the next generation.

Modern AI violates all three.

The experiment

109 nodes. Every node connected to every node.

18 sensors · the board, 9 cells × mine / theirs 82 hidden · free, no layers, no roles 9 outputs · one per cell

11,881 weights. Not one of them was placed by hand.

node = tanh( Σ all nodes × weights + bias )
every tick, forever

How a move happens

It fires when it is ready. Not when we ask.

  • The opponent moves. The brain keeps ticking.
  • Each tick, nine output nodes rise and fall.
  • The first one past the threshold is the move.
  • If that cell is occupied, the brain dies.
  • If nothing fires in 100 ticks, it froze. It dies.
Learning

No teacher. No gradient. Just survival.

01 · BIRTH

50,000 random brains

Every weight is noise. None of them know what a board is.

02 · LIFE

150 games each

Against a random opponent. Half as X, half as O.

03 · DEATH

First mistake kills

Fitness is how many legal moves it made before dying, plus the games it won.

04 · BREED

Top 20% reproduce

Children mix two parents' weights and get a little mutation. Repeat.

Scale

Every brain, every game, every tick at once

  • 50,000 brains × 150 games = 7.5 million games per generation
  • All of them tick in lockstep as one matrix multiply
  • 35 seconds per generation on an RTX A6000
  • A 200-brain CPU run took the same time for 0.05% of the search

Results so far

The brain can play. It cannot yet obey.

diagnostic

When we handle legality for it, the same brain wins 78% against a random player after 500 generations, and takes longer to decide as it gets better. The architecture works.

faithful

Left to learn legality from survival alone, every run so far is flat. Best lifespan: 6 games. Most brains die on their first move.

Why legality is hard

Eighteen weights against a wall of noise

  • Each output listens to 82 hidden nodes with random weights. That is a roar of about ±1.4 before the squash.
  • To stay quiet on an occupied cell, two sensor wires per cell must become strongly negative. Nine cells, eighteen wires, out of 11,881.
  • Crossover between unrelated parents tears a half-solution apart.
  • Nature had the same problem. Nature had a billion years.
What's next

Change the starting conditions, never the rules

A

Let it run

400 generations of 50,000 brains is the largest search yet. It is running now.

B

A real lifespan

Play games in sequence so the brain carries state from one game to the next.

C

Gentler breeding

Clone and mutate, or cross only near relatives, so learned structure survives.

D

Quieter birth

Start with smaller or sparser random weights. Still no design. Just less noise.

None of these tell the brain what a legal move is.
